# 先改，再渲染
一句话：片子先在草稿里改对，最后只渲染一次。
时长：40
读音：cocut→扣卡特

## 0a 钩子 push
画面：深夜，屏幕上渲染进度条卡在 37%，旁边一杯早就凉了的咖啡
旁白：改一个字，又要等它渲染二十分钟。
小字：渲染中 37%

## 0b 痛点 pan
画面：一排缩略图，第一版、第二版……第九版，每版只差一句字幕
旁白：第九版了，其实只改了一句话。

## 1a 转折 pull
画面：浏览器里打开一部能播的草稿，文字卡代替画面，字幕和配音都在
旁白：换个顺序。先看草稿，不先出视频。
小字：草稿 · 0 次渲染

## 1b 能力 push
画面：鼠标在画面上点一下，弹出一行意见框
旁白：哪里不对，就在画面上点哪里。

## 1c 能力 static
画面：拍点条上一格变短，后面的拍点自动往前顺延
旁白：改一句只重配一句，时间自动接上。

## 2a 协作 pan
画面：几个不同的 AI 标志围着同一份草稿，各自留下一条意见
旁白：任何 AI 都能读同一份草稿，留同一种意见。

## 2b 翻转 push 高潮
画面：文字卡一张张翻成电影画面，节奏和字幕一点没变
旁白：主线定了，再一拍一拍换上好画面。

## 3a 收束 pull
画面：只有一次导出按钮被按下，进度条一口气走完
旁白：最后，只渲染一次。

## 3b 片名
旁白：共剪 cocut。
小字：先改，再渲染
